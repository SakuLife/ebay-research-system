## 送る前の確認事項

1. **納品日 8/8（金）は仮置き**。実際に間に合う日付に差し替えること。
   ⚠️ 仕入先側が楽天503（メンテ）・Amazon PA-API 403（アカウント資格要件未達）で止まっており、
   現在はSerpAPI（無料枠100回/月）のフォールバックで動いている。
   **納品前に楽天の復旧確認、またはYahoo!ショッピングのAPIキー投入が必要**。
2. 数字（63%→70%）は**実測値なのでそのまま出して問題ない**。
   ただし「70%」を約束値と受け取られないよう、「測定条件つき」であることは崩さないこと。
3. 支払済み費用への直接回答（返金可否）は**あえて書いていない**。
   納品日を示すことで「返金ではなく納品で応える」姿勢を示す構成。
   先方が再度返金を求めてきた場合は、別途方針を決めて返答する。
4. **署名・名乗りは入れない**（ココナラのアカウント名で表示されるため）。
