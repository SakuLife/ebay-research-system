### 事実確認（回答の根拠）

**Q1. 6月の送料修正とは何か / 送料は実装されているのか**

- 6/18のコミット内容（記録あり）:
  - eBay出品の送料を**出品側の通貨のままドルとして計算していた不具合**を修正
    （例: 英ポンド表記の送料をそのままドルとして扱っていた）
  - 配送オプションが複数ある場合、先頭固定ではなく**最安のものを採用**するよう変更
  - これは「同じ商品の中でどの出品が本当に一番安いか」を判定する計算に使う
- **R列（販売送料）は実装済み。** 0が多いのはeBayに送料無料の出品が多いため。
  実際に値が入っている行: **672行=$73.00 / 690行=$7.10 / 699行=$13.80**
- **発送時の国際送料も計算済み。** 検索ベースシートで重量・寸法から
  配送業者と発送方法を自動選定し、利益額に反映している
  （例: 973g → CPaSS_Economy、eBay手数料12.70%を控除）

**Q2. どのように確認しているのか**

- 自動チェック（全件）: 画像照合による同一商品判定／中古除外／海外サイト除外／
  説明書のみ・箱のみ等の除外
- 精度の実測: 30件の固定サンプルで同一商品を正しく特定できる割合を測定（約7割）
- ただし**今回はテスト行・不具合行を残したまま案内**しており、確認の甘さは事実
