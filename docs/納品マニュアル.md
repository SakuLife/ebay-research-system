# eBayリサーチ自動化システム 操作マニュアル

このシステムは、eBayで売れている商品を見つけ、日本国内の通販サイトから同じ商品を最安値で探し、
利益が出るかどうかを自動で計算してスプレッドシートに書き出します。

---

## 1. 全体の流れ

```
スプレッドシートにキーワードを入力
        ↓
  ボタンを押す
        ↓
① eBayで売れている商品を探す
② 同じ商品が、もっと安く出ている出品がないか探し直す
③ 商品名を日本語に翻訳する
④ 国内の通販サイト（楽天・Google Shopping経由の各店）から最安値を探す
⑤ 送料・手数料・為替を含めて利益を計算する
        ↓
スプレッドシートに結果が並ぶ（利益が出るものだけ）
```

最終的な仕入れ判断（本当に同じ商品か、在庫はあるか）は、
出力されたリンクを見てご確認いただく前提の設計です。

---

## 2. 事前にご準備いただくもの

4つのアカウントとキーが必要です。**すべて無料で始められます**
（SerpAPIのみ、本格運用時に有料プランが必要になります）。

| # | サービス | 用途 | 費用 |
|---|---|---|---|
| 1 | eBay Developers | eBayの商品情報を取得 | 無料 |
| 2 | SerpAPI | 国内通販サイトを横断検索 | 無料枠100回/月・以降は有料 |
| 3 | 楽天ウェブサービス | 楽天市場から仕入先を検索 | 無料 |
| 4 | Google Gemini | 商品名の翻訳・画像での同一商品判定 | 無料枠あり |

## 3. APIキーの取得手順

### 3-1. eBay Developers

1. https://developer.ebay.com/ にアクセス
2. 右上の「Join」→「Register Now」から登録
   - **登録完了まで1〜2日かかる場合があります。早めにお願いします**
3. 登録後、「My Account」→「Application Keysets」を開く
4. **Production**（本番用）の欄から以下を控える
   - `App ID (Client ID)`
   - `Cert ID (Client Secret)`

> ⚠️ Sandbox（テスト用）とProduction（本番用）でキーが別々です。
> **必ず Production のほうを使ってください。** Sandboxのキーだと実在の商品が取れません。

### 3-2. SerpAPI

1. https://serpapi.com/ でアカウント作成
2. ダッシュボードの「Your Private API Key」を控える

**料金プラン**

| プラン | 月額 | 検索回数 | 目安 |
|---|---|---|---|
| Free | 無料 | 100回 | 動作確認用 |
| Starter | $25 | 1,000回 | お試し運用 |
| Developer | $75 | 5,000回 | **月500〜1,000商品の本格運用** |

1商品あたり平均5回程度のクレジットを消費します。
まずFreeプランで動作を確認し、問題なければDeveloperプランへ切り替えるのがおすすめです。

### 3-3. 楽天ウェブサービス

> ⚠️ 2026年に楽天のAPIが刷新されました。**以前のアプリIDは使えません。**
> 新しくアプリを登録し直す必要があります。

1. https://webservice.rakuten.co.jp/ にログイン
2. 「アプリ一覧」→ アプリがなければ「Create」（新規作成）
3. フォームに以下を入力

| 項目 | 入力内容 |
|---|---|
| Application name | 任意（例: `eBay Research Tool`） |
| Application URL | お持ちのサイトのURL（無ければGitHubなどでも可） |
| Application type | `Web Application` |
| **Allowed websites** | **ドメイン名のみ**を1行ずつ（例: `github.com`） |
| Application description | 任意（例: `リサーチ用`） |
| Purpose of data usage | 下記の例文をコピーしてください |
| Expected QPS | `1` |
| API Access Scopes | **`Rakuten Ichiba API` だけ**にチェック |

**Purpose of data usage の例文**

```
Retrieving product names, prices, and stock availability from Rakuten Ichiba
to compare them with overseas marketplace prices, in order to support sourcing
decisions for a small resale business. The data is used internally for price
comparison only and is not redistributed or republished.
```

4. 作成後、以下の3つを控える
   - `applicationId`
   - `accessKey`
   - `affiliateID`（任意。設定すると楽天のアフィリエイト報酬が付きます）

#### ⚠️ ここでつまずきやすい3点

1. **Allowed websites には「ドメインだけ」を入れる**
   `https://` やパス（`/user/repo`）を含めると **`Invalid domain/IP`** で登録が弾かれます。
   - ❌ `https://github.com/YourName/your-repo`
   - ⭕ `github.com`

2. **入力欄に薄字で出ている楽天のドメイン例をそのまま入れない**
   `rakuten.co.jp` や `webservice.rakuten.co.jp` を入れると、
   API実行時に **`403 Access from this IP address is not allowed`** で弾かれます。
   あくまで**ご自身のドメイン**を入れてください。

3. **`localhost` は使えません**（`503 Authentication service error` になります）

### 3-4. Google Gemini

1. https://aistudio.google.com/apikey にアクセス
2. 「Create API key」でキーを作成し、控える

### 3-5. Googleスプレッドシート連携（サービスアカウント）

こちらは**当方で設定済みのものをお渡しします**。
`ebaysystem-xxxxx.json` というファイルを、システムのフォルダに置いてください。

## 4. 設定ファイル（.env）の書き方

システムのフォルダにある `.env.example` を `.env` という名前でコピーし、
控えたキーを `=` の右側に貼り付けてください。

```
# eBay API（Productionのキー）
EBAY_CLIENT_ID=（App ID）
EBAY_CLIENT_SECRET=（Cert ID）
EBAY_USE_SANDBOX=false

# 楽天
RAKUTEN_APPLICATION_ID=（applicationId）
RAKUTEN_ACCESS_KEY=（accessKey）
RAKUTEN_AFFILIATE_ID=（affiliateID・任意）
RAKUTEN_REFERER=https://github.com/

# SerpAPI
SERP_API_KEY=（Private API Key）

# Gemini
GEMINI_API_KEY=（APIキー）
GEMINI_MODEL=gemini-flash-latest

# Googleスプレッドシート
GOOGLE_SERVICE_ACCOUNT_JSON=（お渡しするjsonファイルのフルパス）
SHEETS_SPREADSHEET_ID=（スプレッドシートのURL）
```

> ⚠️ **`RAKUTEN_REFERER` は必須です。**
> 楽天アプリ登録の `Allowed websites` に入れたドメインと**同じもの**を、
> `https://` を付けて記入してください。ここが一致していないと
> `403 REQUEST_CONTEXT_BODY_HTTP_REFERRER_MISSING` というエラーになります。
>
> ⚠️ `.env` はパスワードと同じ扱いです。他人に渡さないでください。

## 5. 使い方

### 5-1. キーワードを登録する

スプレッドシートの **「設定＆キーワード」シート** の E列に、検索したいキーワードを入力します。
1行に1キーワード、日本語・英語どちらでも構いません。

> **ここが結果を最も大きく左右します。** 同じシステムでも、キーワード次第で
> 「9件出る」ことも「0件」にもなります。下記をご確認ください。

#### ✅ 結果が出やすいキーワード（実測で確認済み）

**メーカー名・ブランド名で、型番が決まっている日用品・消費財**が最も安定します。

| キーワード | 実測結果 |
|---|---|
| `Milbon`（ミルボン） | **5件出力**（利益 ¥9,723〜15,331） |
| `Zojirushi`（象印） | **3件出力**（利益 ¥5,538〜6,484） |
| `Shiseido`（資生堂） | **2件出力**（利益 ¥6,607〜6,963） |

この3つで**9件すべてが利益5,000円以上**という結果になりました。

ほかに相性が良いと考えられるジャンル:
ヘアケア・化粧品・小型調理家電・オーディオ・文具・調理器具など、
**「日本の通販サイトに新品の在庫が常にあり、型番で特定できるもの」**です。

#### ❌ 結果が出にくいキーワード

| キーワード | 実測結果 |
|---|---|
| `Iron man` | 90商品を処理して**0件** |
| `BANDAI` | 40商品を処理して**0件**（使える行なし） |
| `Kaiyodo`（海洋堂） | 0件 |

理由は、これらが**作品名・キャラクター名や、限定品・フィギュア中心のブランド**だからです。

- 一点物・限定版・受注生産が多く、**日本国内に新品の在庫がない**
- 同じ商品名でもバージョン違いが多数あり、同一商品と確定できない
- 中古・プレミア価格が中心で、仕入れて利益を出す構造になっていない

**キーワードを増やす前に、まず上記の「出やすい」系統で数を回すことをおすすめします。**
効かないキーワードは、結果が出ないだけでなく**API利用料だけ消費します**。

### 5-2. 実行する

メニューの **「リサーチツール」→「自動リサーチ実行」** を押します。

処理には時間がかかります（1キーワードあたり十数分程度）。
実行中はパソコンを閉じても問題ありません。

### 5-3. 結果を見る

**「入力シート」** に結果が1行ずつ追加されます。

| 列 | 内容 |
|---|---|
| A | 日付 |
| B | 商品名（eBayのタイトル） |
| C・D | カテゴリ |
| E | 新品／中古 |
| F〜N | **国内仕入先①②③**（店名・リンク・価格） |
| O | **eBayの出品リンク**（同一商品の最安出品） |
| P | 販売数 |
| Q・R | eBayの販売価格・送料（米ドル） |
| S・T | **還付抜きの利益額・利益率** |
| U・V | 還付ありの利益額・利益率 |
| W | ステータス |
| X | 出品フラグ（出品したら手で印を付ける欄） |
| Y | メモ（処理の履歴） |

**Y列のメモに「最安値検索: $◯◯→$◯◯に差替」と入っている行**は、
最初に見つけた出品より安い同一商品が見つかり、そちらに置き換えたことを示します。

## 6. 検索条件の調整

「設定＆キーワード」シートで、以下を変更できます。

| 設定 | 意味 | 上げるとどうなるか |
|---|---|---|
| 最低利益額 | この金額未満の商品は出力しない | 出力が厳選される |
| 最小販売数 | eBayでこの回数以上売れた商品のみ対象 | 出力が減り、**クレジット消費も減る** |
| 最低価格 | この価格未満の商品は対象外 | 出力が減り、クレジット消費もやや減る |
| 1キーワードあたりの検索数 | 1キーワードで何商品まで見るか | 出力が増え、**クレジット消費も増える** |

クレジットを節約したい場合は、**最小販売数を上げる**のが最も効果的です。

## 7. 精度について（正直にお伝えします）

**同一商品を正しく特定できる割合は約7割**です（実データ30件での測定値）。

なお、キーワードを適切に選んだ場合の実測結果は以下のとおりです
（`Zojirushi` `Milbon` `Shiseido` `Pilot` の4語で1回実行）。

| 項目 | 結果 |
|---|---|
| 出力された行 | **9件** |
| そのうち利益5,000円以上 | **9件（100%）** |
| 商品違い等のエラー行 | **0件** |
| 利益の平均 | 約9,300円 |
| 利益の最大 | 15,331円 |

残り3割で取りこぼす主なものは以下で、これらは仕組み上どうしても拾えません。

- **カスタム品・改造品**（装飾を施した時計など）… 同じ商品が世界に1点しかない
- **汎用アクセサリ**（複数機種対応の互換品）… 商品を特定する型番がない
- **ノーブランド品**… 識別できる情報がタイトルにない

また、以下は**最終的に人の目でのご確認をお願いします**。

- 出力された国内仕入先が、本当に同じ商品か
- 在庫があるか（在庫切れを除外していますが、完全ではありません）
- 新品か中古か（中古は除外していますが、表記のない出品は判別できません）

### 自動で除外しているもの

以下はシステム側で自動的に候補から外しています。実行ログにも件数が出ます。

| 除外対象 | 理由 |
|---|---|
| **中古品** | 新品前提の利益計算に中古価格が混ざると数字が嘘になるため。メルカリ・ヤフオク等の個人間取引も対象 |
| **海外ショップ** | ご要望は国内仕入のため。Google検索には `.fr` `.pl` 等の海外通販が混ざります |
| **説明書のみ・箱のみ・部品取り** | 商品本体ではないため |

> 万一、国内のショップが誤って除外されている場合は、ログに店名が出ますのでお知らせください。
> 判定リストに追加して救済できます。

## 8. 困ったときは

| 症状 | 原因と対処 |
|---|---|
| 楽天だけ結果が0件 | そのキーワードの商品が日本の楽天に無い（中古のみの場合も除外されます）。異常ではありません |
| `REQUEST_CONTEXT_BODY_HTTP_REFERRER_MISSING` | `.env` の `RAKUTEN_REFERER` が未設定か、楽天アプリの `Allowed websites` と不一致 |
| `Invalid domain/IP`（楽天のアプリ登録時） | `Allowed websites` にURLを入れている。ドメインのみにする |
| `403 Access from this IP address is not allowed` | `Allowed websites` に楽天のドメインを入れている。自分のドメインに変える |
| SerpAPIが動かない | 無料枠（100回/月）を使い切った可能性。ダッシュボードで残数を確認 |
| eBayの商品が取れない | `EBAY_USE_SANDBOX` が `true` になっていないか確認（`false` が正解） |
| 結果がまったく出ない | キーワードが抽象的すぎる可能性。商品名・ブランド名に近い語のほうがヒットします |
